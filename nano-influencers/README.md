# Nano Influencers — Frontend

A responsive React/Vite implementation of the supplied Nano Influencers Figma frontend references.

## Included
- Dashboard
- Campaign services
- Campaign creation flow
- Ongoing campaigns
- Pending campaigns
- Campaign notifications
- Wallet
- Responsive mobile bottom navigation
- Functional dialogs for funding, creating campaigns, pausing/deleting campaigns, support and notifications
- Local demo state for campaigns and wallet activity

## Run
```bash
npm install
npm run dev
```

Production build:
```bash
npm run build
npm run preview
```

This is a frontend-only implementation. Payment processing, authentication, APIs and persistence are intentionally represented with local demo state and UI interactions.
